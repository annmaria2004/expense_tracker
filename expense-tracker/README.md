# Expense Tracker

A simple Expense Tracker built using FastAPI, MongoDB, and Jinja2 Templates.

## Features

- Add expenses
- Edit expenses
- Delete expenses
- Monthly expense summary
- MongoDB database integration

## Tech Stack

- FastAPI
- MongoDB Atlas
- Jinja2
- Python

## Run Locally

```bash
pip install -r requirements.txt
uvicorn main:app --reload
